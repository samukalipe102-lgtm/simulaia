# Recursos de build do app desktop

Coloque aqui o ícone do aplicativo:

- **`icon.ico`** — ícone do Windows (recomendado 256×256, formato `.ico`).

Se não houver `icon.ico`, o Electron/electron-builder usa o ícone padrão do
Electron. O app funciona normalmente mesmo sem ícone personalizado.

Para gerar um `.ico` a partir de um PNG, você pode usar qualquer conversor
online de PNG→ICO (ex.: um PNG quadrado de 256×256).
